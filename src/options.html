    • Origin Private File System entry points

    Important limitation

    Defense in depth, not a browser patch

    An extension cannot rewrite an already-running service worker or eliminate every timing side channel. Use the popup’s purge control after installing on tabs that were already open, then reload them.

    Data handling

    Local by design

    No analytics, remote code, network service, or runtime dependency is included. Settings sync through Chrome; event records remain in extension-local storage.
