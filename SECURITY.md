# Security policy

FROST Guard is a defensive prototype. It reduces exposure to the documented
FROST attack path but is not a browser-engine patch and has not received a
formal security audit.

## Supported version

Only the latest release in this codebase is supported. The initial supported
release is 0.2.0, reviewed on 2026-07-14.

## Reporting a vulnerability

Use the repository's **Security** tab to submit a private vulnerability report.
Do not include sensitive browsing data, full URLs with secrets, or exported
event logs in a public issue.

Useful reports include:

- Chrome version and operating system.
- A minimal page that reaches OPFS despite protection being active.
- Whether the bypass uses a window, iframe, dedicated worker, shared worker,
  service worker, worklet, or another execution context.
- Whether the tab was already open when the extension was installed or enabled.

## Security boundaries

The extension intentionally does not transmit telemetry. Event records remain
in `chrome.storage.local`; settings and permanent exceptions use
`chrome.storage.sync`. A page can attempt to spoof visible warning events, so
only confirmed file-system-growth events generated by the isolated monitor can
produce a badge or desktop notification. Growth alerts never auto-purge data.
